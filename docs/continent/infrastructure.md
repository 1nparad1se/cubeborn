Все координаты фиксированы и сняты с **замороженного** рельефа (хеш `ba3a99f6b0739a00…`, см. geography.md §14). Источник истины — авторские файлы `tools/continent/world/*.ts`; раскладку считает `npx tsx tools/continent/world/build.ts` → `world/generated.json`, проверяет `npx tsx tools/continent/world/validate.ts` → `docs/continent/world_validation.json`.

Координаты: X на восток, Z на юг; «пов.» — поворот фасада ×90° (0 = фасад на юг/к дороге). Размер — ширина × глубина в блоках.
