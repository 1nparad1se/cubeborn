# Cubeborn

Оригинальный воксельный survivor-like / roguelite для телефона и браузера.
Герой атакует сам, игрок только двигается. Опыт, уровни, эволюции оружия, элиты и многофазные боссы,
6 карт, 9 героев, 46 видов оружия (23 базовых + 23 эволюции), 24 пассивки, 45 врагов, 12 боссов,
42 достижения, постоянные улучшения, 4 сложности. Тексты RU/EN.

## Запуск

```bash
npm install
npm run dev        # локально: http://localhost:5173 (флаг --host открывает и для телефона в той же сети)
npm run build      # продакшен-сборка в dist/
npm run preview    # проверить сборку
npm run sim -- blightwood bram normal 3   # безголовая симуляция баланса
```

`dist/` — статический сайт: его можно залить на любой хостинг (Netlify, GitHub Pages, itch.io как HTML5-игру).

## Сборка под Android / iOS (Capacitor)

```bash
npm run build
npm i @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
npx cap add android      # или ios
npx cap sync
npx cap open android
```
Конфиг уже лежит в `capacitor.config.json` (webDir = dist).

## Управление
- Телефон: плавающий стик — ведите пальцем в любом месте экрана.
- ПК: WASD / стрелки или зажатая левая кнопка мыши; Esc / P — пауза. Геймпад: левый стик, Start — пауза.

## Архитектура
- `src/data` — весь контент (герои, оружие, пассивки, враги, боссы, карты, сложности, улучшения, достижения).
- `src/game` — симуляция без рендера (пулы, пространственная сетка, поле потоков для навигации, боссы, спавнер).
- `src/render` — Three.js: инстансинг воксельных моделей, шейдерная земля, свет, тени, частицы.
- `src/audio` — синтез звуков и процедурная музыка на WebAudio.
- `src/ui`, `src/meta`, `src/i18n` — интерфейс, сохранения, локализация.

Вся графика, модели, иконки, звуки и музыка созданы процедурно в коде. Шрифты Press Start 2P и Rubik — SIL OFL.
